# קטלוג דוגמאות — טוב מול רע, עם הסבר

הקובץ שפותחים כשלא בטוחים אם טקסט טוב. כל דוגמה כוללת **למה** — כי הכלל
מעביר יותר מהתיקון.

---

## 1. ממשק

### כפתורים
| ✗ | ✓ | למה |
|---|---|---|
| "שמור" | "שמירה" | לשון זכר יחיד. שם פועל נייטרלי |
| "אישור" | "שליחה למוזמנים" | "אישור" לא אומר מה יקרה |
| "המשך" | "הוספת מוזמנים" | הכפתור אומר את הפעולה |
| "לחץ כאן" | "צפייה ברשימה" | שריד משנות ה-2000 |
| "בטל" | "ביטול" | מגדר |

### מצבים ריקים
```
✗ "לא נמצאו מוזמנים"
   → דיווח על ריקנות. משתמש חדש לא יודע מה עכשיו.

✓ "עדיין אין מוזמנים — בואו נוסיף את הראשונים"
   [ הוספת מוזמן ]  [ העלאת רשימה מאקסל ]
   → "עדיין" מרמז שזה זמני. שתי דרכים להתחיל.
```

```
✗ "אין נתונים להצגה"
   → "נתונים" היא מילה של תוכנה.

✓ "השולחנות עוד ריקים. אפשר לשבץ ידנית, או לתת ל-VEYA להציע סידור"
   → מציג את שתי הדרכים, ומחזיר שליטה ("או").
```

### שגיאות
```
✗ "אירעה שגיאה"
   → לא אומר מה קרה ולא מה עושים. תלונה, לא הודעה.

✓ "לא הצלחנו לטעון כרגע. ננסה שוב"
   → "לא הצלחנו" = האשמה עלינו. "ננסה" = יש צעד הבא.
```

```
✗ "מספר טלפון שגוי"
   → "שגוי" מאשים. המשתמש מרגיש טיפש.

✓ "נראה שהמספר לא תקין — בואו נבדוק אותו שוב"
   → "נראה ש" מרכך. "בואו" = יחד.
```

```
✗ "הקובץ חורג מהגודל המותר"
   → לשון תקנון. לא אומר מה הגודל המותר.

✓ "התמונה גדולה מדי — עד 3MB"
   → הגבול מיד, בלי לחפש.
```

### הצלחה
```
✗ "מעולה! הפרטים נשמרו בהצלחה! 🎉"
   → שלוש חגיגות על פעולה שגרתית. מתיילד.

✓ "נשמר"
   → זה כל מה שצריך.
```

```
✗ "ההודעות נשלחו"
✓ "התזכורת נשלחה ל-45 מוזמנים"
   → מספר = ביטחון. המשתמש יודע שזה באמת קרה.
```

### הושבה — הרגישות ל-AI
```
✗ "האלגוריתם שיבץ 240 מוזמנים בהצלחה"
   → "אלגוריתם" מפחיד. "שיבץ" נשמע סופי. איפה השליטה שלי?

✓ "הצענו סידור לכל מי שאישר. אפשר לשנות כל שולחן"
   → "הצענו" = הצעה. "אפשר לשנות" = השליטה נשארה אצלכם.
```

```
✗ "חריגה מקיבולת השולחן!"
✓ "שולחן 7 מלא. אפשר להוסיף בכל זאת"
   → אזהרה רכה: מיידעת, לא חוסמת.
```

## 2. WhatsApp

### הזמנה
```
✗ "שלום, הנך מוזמן לחתונה של דנה ויואב בתאריך 15.08.2026 בשעה 19:00
   באולמי הגן. נא לאשר הגעה באמצעות הקישור המצורף."

   למה נכשל: "הנך" ארכאי · "נא לאשר" לשון פקודה ·
   הכול בפסקה אחת בלי אוויר · אפס רגש · לשון זכר יחיד.

✓ "דוד שלום,
   יש רגעים שמסמנים התחלה חדשה — וזה אחד מהם.
   דנה ויואב מתכבדים להזמינכם לחגוג עמם את יום נישואיהם.

   📅 15.08.2026 · 19:00
   📍 אולמי הגן

   נשמח לאישור השתתפותכם: [קישור]"

   למה עובד: פנייה בשם · משפט רגש אחד · המידע מופרד וסרוק ·
   לשון רבים · בקשה אחת בסוף.
```

### תזכורת
```
✗ "טרם אישרתם הגעה. אנא אשרו בהקדם."
   למה נכשל: מאשים · "אנא"+"בהקדם" = לחץ · אפס חום.
   (זה הנוסח המקובל בשוק — ובדיוק לכן זו הזדמנות בידול.)

✓ "היי דוד, רצינו לוודא שההזמנה שלנו הגיעה אליכם 🙂
   נשמח לדעת אם נתראה: [קישור]"
   למה עובד: הסיבה לפנייה היא שלנו ולא כישלון שלהם.
```

### תזכורת אחרונה
```
✗ "זוהי התזכורת האחרונה. מי שלא יאשר לא יוכל להיכנס."
   למה נכשל: מאיים. פוגע בבעלי האירוע מול המוזמנים.

✓ "דוד, אנחנו סוגרים מחר את הרשימה לאולם.
   מגיעים? [קישור]"
   למה עובד: דחיפות אמיתית ומוסברת — לא איום.
```

### תודה
```
✗ "תודה על השתתפותכם באירוע."
   למה נכשל: לשון חברה. "השתתפותכם" = כנס, לא חתונה.

✓ "דוד, תודה שהייתם איתנו.
   זה לא היה אותו ערב בלעדיכם ❤️
   דנה ויואב"
   למה עובד: "שהייתם איתנו" אישי · לב אחד בלבד · חתום בשמם.
```

## 3. שיווק

### כותרות
```
✗ "הפלטפורמה המתקדמת ביותר לניהול אירועים בישראל"
   למה נכשל: מדבר על עצמו · "מתקדמת ביותר" לא נבדק · אפס כאב.

✓ "בלי אקסל. בלי לרדוף. בלי לנחש כמה יגיעו."
   למה עובד: שלושה כאבים אמיתיים בשמם. הזוג מזהה את עצמו.
```

```
✗ "נהלו את החתונה שלכם בקלות ובמהירות!"
   למה נכשל: "בקלות ובמהירות" קלישאה · סימן קריאה · חתונה בלבד.

✓ "תדעו בדיוק כמה מגיעים. שבועיים לפני."
   למה עובד: תוצאה מדידה + מסגרת זמן.
```

### יתרונות
```
✗ "מערכת RSVP אוטומטית מבוססת WhatsApp Business API עם מנוע
   אלגוריתמי לאופטימיזציית הושבה"
   למה נכשל: כתוב למפתחים.

✓ "אישורי הגעה בוואטסאפ — המוזמנים לוחצים כפתור אחד,
   ואתם רואים את המספר מתעדכן לבד."
   למה עובד: מה קורה + מה זה נותן לי. שני הצדדים.
```

### CTA
```
✗ "הירשמו עכשיו!"   → פעולה שאנחנו רוצים, לא שהם רוצים.
✓ "מתחילים לתכנן"   → הפעולה שהם באו בשבילה.
```

## 4. חמש הטעויות שחוזרות הכי הרבה

**1. לשון זכר יחיד** — "בחר", "הזן", "לחץ". → שם פועל.

**2. להאשים** — "שגוי", "לא תקין", "טרם אישרתם". → "נראה ש…" / הסיבה אצלנו.

**3. לדבר על התוכנה** — "המערכת תשלח", "האלגוריתם קבע". → "נשלח", "הצענו".

**4. חתונה בטקסט משותף** — "מוזמני החתונה" בקומפוננטה גנרית. → לקסיקון.

**5. להתלהב מדי** — "מעולה!", "מדהים!", 🎉. → עובדה שקטה.

---

## 5. שלוש שאלות כשתקועים

1. **איך הייתי אומר את זה לחבר?** — כתוב את זה, ואז נקה משלב.
2. **מה המשתמש מפחד ממנו כאן?** — ענה על הפחד, לא על הפעולה.
3. **מה קורה אחרי הלחיצה?** — אם הטקסט לא אומר את זה, הוא לא מוכן.
