## מי VEYA כשהיא מדברת

**חברה חכמה שכבר עברה את זה.**

לא ספק שירות שמתרפס. לא תוכנה שמסבירה את עצמה. לא מפיקת אירועים שמתלהבת
יתר על המידה. חברה — שיודעת בדיוק מה צריך לקרות, מסדרת את זה בשקט, ולא
עושה מזה עניין.

**מה שהיא משדרת בלי לומר את זה:** "אני מחזיקה את זה. אתם יכולים לנשום."

---

## חמשת הטונים — לפי סדר עדיפות

1. **רגועה** — הכי חשוב. המשתמש כבר לחוץ; אנחנו הקול השקט בחדר.
2. **יוקרתית** — מכובדת ומוקפדת. לא מנופחת, לא מתרברבת.
3. **חכמה** — יודעת דברים, אומרת אותם בפשטות. לא מתפארת בטכנולוגיה.
4. **אנושית** — כותבת כמו בן אדם, טועה בענווה, לא מאשימה.
5. **חמה** — אכפת לה. אבל לא מתיילדת ולא מתחנחנת.

**מה שהיא אף פעם לא:** מתלהבת מדי · דחופה · מוכרנית · מתנצלת · טכנית · קרה ·
מצחיקה בכוח · משתמשת בסימני קריאה כדי לייצר אנרגיה.

## סגנון לפי סוג משתמש

### זוג מתחתן (הליבה)
לשון רבים, חמה, שותפה. מותר רגש. **"החתונה שלכם"**, **"נשמח"**, **"יחד"**.
```
✓ "עדיין אין מוזמנים — בואו נוסיף את הראשונים"
✗ "רשימת המוזמנים ריקה"
```

### משפחה חוגגת (בר/בת מצווה, ברית)
דומה, אבל **פחות רומנטי ויותר מכבד**. המוקד הוא הילד/התינוק והמשפחה, לא
"אתם השניים".
```
✓ "בר המצווה של יונתן — הכול מסודר במקום אחד"
✗ "היום הגדול שלכם מתקרב"
```

### מארגן אירוע עסקי
**ענייני, מדויק, בלי רגש.** לא קר — אבל בלי "מתרגשים". מונחים: משתתפים,
מחלקה, אישור השתתפות.
```
✓ "247 משתתפים אישרו. 53 ממתינים לתשובה"
✗ "כבר 247 אישרו — מרגש!"
```

### מוזמן (מקבל הודעה)
לא לקוח שלנו — **אורח של הלקוח שלנו**. הקול הוא של **בעלי האירוע**, לא של
VEYA. VEYA לא מזכירה את עצמה בהודעה למוזמן, אלא אם יש סיבה.
```
✓ "דנה ויואב מתחתנים — ואתם איתם"
✗ "VEYA מזמינה אותך לאשר הגעה"
```

### מבקר בדף הנחיתה (עדיין לא לקוח)
מותר להיות חד יותר ולדבר על הכאב ישירות — אבל **בלי לחץ מכירתי**.
ראה `marketing-copy.md`.

## סימני פיסוק ואמוג'י

- **סימן קריאה:** לכל היותר אחד בטקסט. לרוב — אפס.
- **שלוש נקודות:** רק במצבי טעינה ("טוען נתונים…") — עם התו `…`, לא `...`
- **מקף מפריד:** `—` (em dash) לתוספת מחשבה. זה הקצב של VEYA.
- **אמוג'י בממשק:** מעט מאוד, פונקציונלי בלבד (🔒 לנעילה, ✎ לעריכה).
- **אמוג'י בוואטסאפ:** 2–4 בהודעה, כמידע ולא כקישוט — 📅 תאריך · 📍 מקום.
- **אין אף פעם:** 🎉🥳💃🕺✨🔥 — רועש וזול.

## המקרים שהכי קל להיכשל בהם

**שגיאה** — מה קרה + מה עושים, בלי להאשים:
```
✓ "לא הצלחנו לשמור את הפרטים. נסו שוב"
✗ "אירעה שגיאה בעת שמירת הנתונים"
```

**הצלחה** — לאשר ולהתקדם, בלי לחגוג:
```
✓ "נשמר"  ·  "12 מוזמנים נוספו לרשימה"
✗ "מעולה! הפרטים נשמרו בהצלחה! 🎉"
```

**מצב ריק** — הזמנה לפעולה, לא דיווח על ריקנות:
```
✓ "עדיין אין מוזמנים — בואו נוסיף את הראשונים"
✗ "לא נמצאו מוזמנים"
```

**אישור לפני פעולה הרסנית** — ברור על מה מוותרים:
```
✓ "להסיר את דנה מהרשימה? אפשר להוסיף אותה שוב אחר כך"
✗ "האם אתה בטוח?"
```
